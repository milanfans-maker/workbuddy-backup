# QQ 四国军棋 .jgs 复盘文件格式规范

基于 6 个真实 .jgs 文件（布局库，步数 318/22/67/72/35/205）逆向实测。

## 文件结构

```
偏移 0x00         文件头（前 0x20 字节含 magic "JGS" 等，不参与解析）
偏移 0x20         4 个玩家块，每块 88 字节
偏移 0x19B/0x19C  指令区（双偏移容错，实测首条 0x5F 在 0x19C）
```

## 玩家块（88B × 4）

| 偏移 | 长度 | 内容 |
|------|------|------|
| p+0x00 | 1 | 颜色字节：0=黄=下 / 1=蓝=左 / 2=绿=上 / 3=紫=右（`BYTE_COLOR=['黄','蓝','绿','紫']`；2026-08-18 按用户真实映射修正，旧映射 `0=绿=上/1=紫=右/2=黄=下/3=蓝=左` 已废弃。6_21 实测：0=黄=大丈夫、1=蓝=习掼叻、2=绿=暴暴寒、3=紫=Ella乐乐） |
| p+0x08 | 20 | 玩家名（GBK 编码） |
| p+0x1C | 30 | 布局矩阵 30B：6 行 × 5 列，行主序，每格 1 字节棋子码 |

棋子码：0=空、1=司令、2=军长、3=师长、4=旅长、5=团长、6=营长、7=连长、8=排长、9=工兵、10=炸弹、11=地雷、12=军旗。

布局矩阵铺盘规则：第 i 行（0..5）、第 j 列（0..4）→ 棋盘坐标 (i, 5+j)（左上角象限），另一侧按对称性铺（上/下、左/右镜像，每方 25 子，4 方共 100 子）。

## 指令区（每 10B 一条）

- 0x5F = 棋步；0xF5 = 事件（扛旗/战败等）。
- 棋步编码：
  - b1 的位 4-3 = 玩家颜色位 `bits=(b1>>3)&3`。**这是有状态状态机，不是固定映射**：
    - 开局 4 家阶段，其取值 = 玩家块颜色字节 QB 的「(QB+1)&3」偏移（bit=0→块1、1→块2、2→块3、3→块0），等价 `BYTE_COLOR[(bits+1)&3]`（即 `['蓝','绿','紫','黄'][bits]`）。**它不是独立编码**——旧写法 `['紫','黄','蓝','绿'][(b1>>3)&3]` 会把整局方位错误地 180° 旋转（第一步「上黄大丈夫撞左紫Ella」错成「下绿暴暴寒撞右蓝习掼叻」），2026-08-18 已修正。
    - **玩家离场（`0xF5` 事件 code=3/4）后，该颜色位由颜色环后继者继承**：环序=初始位升序 `RING=['蓝','绿','紫','黄']`，跳过已离场者（全离场则不更新）。实测规则：蓝离场→后继者绿继承位0；黄离场→后继者蓝继承位3；绿离场→后继者紫继承位1；多玩家连续离场时取下一个存活后继者。若不处理，离场后走棋会串色（6_21 蓝离场后 bits=0 被固定映射误解为蓝、真值是绿，26 处不一致）。实现：`extractMoves` 维护 `RING/bitOfColor/colorOfBit/active`，`applyExit(ev)` 在 0xF5 code=3/4 时更新映射（`colorOfBit[bx]=cand; bitOfColor[cand]=bx; if(bs!==bx) delete colorOfBit[bs]`）。2026-08-18 修复后 6 文件 719 步 0 不一致。
  - b2b3 = 起点 (纵, 横)；b4b5 = 终点 (纵, 横)
  - **纵坐标自下而上 0..16，解析必须 `16 - y` 翻转**；横坐标直接使用
- 解析时按玩家块顺序推断玩家颜色，用行棋 from 坐标做几何投票（见下）。

### 0xF5 事件编码（战败/退出/结束）

- `b1`：02=超时判负、03=战败、04=退出、05=结束
- `a`：玩家颜色字节（`BYTE_COLOR[a]`）
- `b`：相关参数（`b1=05 && b=4` 为「结束」事件，不输出为玩家步）
- 事件穿插于棋步指令间，`extractMoves` 用 `seq` 保留指令流顺序；事件步不占独立移动步，但在文本/回放中作为独立步骤纳入以保持步号连续。
- **code=3 战败文本（2026-08-18）**：QQ 在棋子扛走某家军旗后会紧接一个该家的 code=3 战败事件，此时文本应为 `军旗被扛，战败`（而非 `自杀战败`）。`jgsToText` 用 `justFlagTaken` 记录上一步是否刚扛某家军旗：若紧随的 code=3 事件的 `evc===justFlagTaken` → `军旗被扛，战败`，否则 `自杀战败`（每个 move 步重置 `justFlagTaken=null`）。**`parseReplay` 事件正则必须含 `军旗被扛，战败`**。实测 6 文件：6_21 321紫 / 6_22_14_57 23黄 / 6_24_16_22 200蓝 为「军旗被扛，战败」；其余 code=3 为真自杀。

## 方位几何推导（动态方位核心）

半场判定（from 坐标）：
- 上 = 行 ≤ 5
- 下 = 行 ≥ 11
- 左 = 列 ≤ 5
- 右 = 列 ≥ 11

`voteDir(coords)`：统计每步 from 坐标归属方位，多数派 ≥2 票返回该方位，否则返回 null（回退颜色字节默认方位）。

```js
function voteDir(coords) {
  var votes = {up:0, down:0, left:0, right:0};
  coords.forEach(function(c) {
    if (c[0] <= 5) votes.up++;
    else if (c[0] >= 11) votes.down++;
    else if (c[1] <= 5) votes.left++;
    else if (c[1] >= 11) votes.right++;
  });
  var top = null, max = 1; // 必须 ≥2 票才生效
  for (var d in votes) if (votes[d] > max) { max = votes[d]; top = d; }
  return top; // null = 回退 byte
}
```

## 方位来源三级优先级（orientSrc）

| 来源 | 适用 | orientSrc | 说明 |
|------|------|-----------|------|
| 行棋坐标几何投票 | .jgs | `geo` | 主路径，voteDir ≥2 票 |
| 玩家块颜色字节默认方位 | .jgs | `byte` | voteDir 不足 2 票时回退 |
| [对局信息]「方位=…」行 | 文本 | `meta` | 最优先，.jgs→文本转换时写入 |
| 布局落点几何推导 | 文本 | `layout` | 无方位行时按布局推导 |

`jgsToText` 输出「方位=上:绿 右:紫 下:黄 左:蓝」（按 dirToColor 上/右/下/左 顺序），保证 .jgs→文本→再导入 方位一致（'meta'）。

## 军旗落点（FLAG_H_DIR）

军旗按方位对齐大本营格：

```js
var FLAG_H_DIR = {up:[[0,7],[0,9]], down:[[16,7],[16,9]], left:[[7,0],[9,0]], right:[[7,16],[9,16]]};
```

`mapLayout` 铺盘时，该方军旗必须落在对应方位的两个大本营格。

## 已知坑

1. **指令区偏移**：0x19B 与 0x19C 都出现过，必须双偏移容错（先试 0x19C，首字节为 0x5F/0xF5 则采用）。
2. **纵坐标翻转**：漏掉 `16-y` 会导致所有步坐标上下镜像。
3. **JS 对象键序陷阱**：`JSON.stringify(obj) === JSON.stringify(expect)` 受键插入顺序影响不可靠；断言对象相等必须逐键比较。
4. **GBK 编码**：玩家名必须用 TextDecoder('gbk') 解码，UTF-8 会乱码。
5. **`dir` 字段已含「家」字**（如"上家"）：渲染模板拼接时不要再加「家」，否则出现「上家家·绿」。
6. **值表改动级联**：棋子价值影响 autoResult 判定（同尽/被吃），改值表后统计基线、后续步状态可能级联变化，必须重跑引擎回归并更新基线。
7. **玩家离场后颜色串色（状态机）**：棋步颜色位 `bits=(b1>>3)&3` 是状态机，玩家自杀战败/退出（0xF5 code=3/4）后其颜色位被颜色环后继者继承，不能用开局固定的 `BYTE_COLOR[(bits+1)&3]` 解码，否则离场后所有走棋串色、且棋盘上该家棋子会"消失但仍在走棋"（6_21 蓝离场后 green 步被显示成蓝、棋子渲染消失）。修复：`extractMoves` 内状态机 + `applyExit`。

## 文本复盘 v2.0 格式

- `[对局信息]`：来源/文件/己方/结果/玩家（颜色=名字）/方位=…
- `[布局]`：`颜色 行,列:棋子名`（每子一行）
- `[行棋]`：`第N步 颜色 起,终 起点棋子名 终点棋子名 结果`（结果：无子/吃子/同尽/炸杀/中炸/挖雷/扛旗/被扛）
- `[统计]`：各家 步数/吃子/被吃/同尽/炸杀/中炸/挖雷/得分/损失/净值
